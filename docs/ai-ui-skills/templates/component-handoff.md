# 组件交付清单

状态：候选 / 已验证（仅实际运行后修改）

| 字段 | 填写项 |
| --- | --- |
| 组件 / 版本 | 名称、语义版本、来源提交 |
| 来源与许可 | 原始 URL、许可文本、版权、素材授权 |
| 目标技术栈 | 平台、框架、版本、浏览器范围 |
| 依赖 | 直接及必要运行时依赖、锁文件、安装方式 |
| 文件白名单 | 相对路径、用途、必要性、哈希（如适用） |
| Token | 原始角色、目标角色、默认值与主题差异 |
| 接口 | props、事件、slot、受控/非受控、错误 |
| 状态 | 默认、焦点、禁用、加载、空态、错误 |
| 可访问性 | 原生语义、名称、键盘、焦点恢复 |
| 隔离验收 | 实际环境、构建命令、交互、截图、结果 |
| 未覆盖 | 不支持的平台、待确认许可、已知缺陷 |

不要自动覆盖、安装未知依赖或将目录整体打包；优先使用目标框架的成熟原语或 UI Vault 现有 Registry。没有真实独立构建不能标为可运行交付。
