# DESIGN.md · 项目设计规范模板

> 候选：先按真实项目填写，不直接覆盖已有文件。证据缺失标未知。

## 1. 产品与任务
- 用户、平台、主要流程、信息密度、视觉目标、禁止事项：待填写。

## 2. 信息架构与布局
- 页面分区、阅读顺序、断点、最小宽度、滚动归属及内容约束：待填写。

## 3. 排版与色彩
- 角色（标题/正文/标签/数据）、字体及许可、字号/字重/行高、CJK 与数字：待填写。
- 基础色、语义角色、深浅主题、状态及实际对比度：待填写。

## 4. 空间、材质与动效
- 空间尺度、边框、层级、阴影、透明回退、动效触发与减少动画：待填写。

## 5. 组件契约
- 原语来源、状态、事件、焦点、键盘、加载与错误恢复：待填写。

## 6. 证据与验收
- 源码路径、参考许可、测试命令、截图条件、实际结果、未验收项：待填写。
- 当前有效规则与历史决策分开，例外写明原因和范围。
