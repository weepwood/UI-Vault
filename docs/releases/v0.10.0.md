# UI-Vault v0.10.0 发布候选

## 主要变更

- 版本级知识证据、反向检索、多资产组合、场景复核及 JSON / DESIGN.md 交付。
- 设计规范编辑器、独立浅深草稿、原生取色、具名方案、历史快照与显式基准迁移。
- Warm Workbench 真实材质附件随方案保存、恢复与交付；保留原有参数协议。
- Foundation 1.1.0：Registry 逐文件 SHA-256 锁、同版本漂移拒绝、局部 CSS、React/Vue 可选门户宿主及实色状态对比适配。
- 设计配方实验室与 Warm Workbench 局部排版、焦点、窄屏及交互动效精修。
- 按需加载、失败重试、存储容量与并发版本检查；干净环境测试夹具独立构建。

## 候选验收

PR #146 集中审查，初次远端 Linux/Windows 单元测试因测试夹具缺少 Foundation 生成产物失败，已修复前置条件。正式验收以最新提交的完整 CI、代码审查、合并后的生产校验及 Release 为准。保留原视觉基线、三栏、展厅内部导航及沙箱权限。不在候选说明中提前宣称发布成功。

## 边界

逐文件摘要校验以可信本地目录为准，不证明许可或外部站点。双主题草稿仅当前会话，保存和导出仍针对当前主题；不承诺跨标签页原子事务。实色状态对比不等同任意主题、透明材质或完整 WCAG 认证。外部 AI Agent 自主运行、完整精选资产人工审查及 WebGPU 实机画质不在本次认证范围内。
