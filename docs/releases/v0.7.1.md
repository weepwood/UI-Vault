# UI-Vault v0.7.1

本版本集中交付 AI UI Skills 使用手册、设计研究知识与跨项目复用模板，不包含仍在开发的 #128，不改主站运行时依赖、既有视觉基线或 iframe 权限。

## 主要变化

- 手册增加 05–14 十个章节，覆盖设计资源、工作流、验收、原始 Skill 研究及跨项目交付。
- 新增 17 项 Skill 研究记录、8 项专业设计知识、4 个 MIT 原创纯文档 Skills 和 5 套模板；同步 HTML、Markdown、机器可读 research.json 与 AGENTS.md。
- 加强手册无障碍语义、命令复制行为、资料一致性、Skill 元数据、许可文件、模板路径和 Token 引用的自动化检查。
- 保留原有站点功能、资产 ID 和设置；不自动安装第三方 Skill，不执行安装指令。
