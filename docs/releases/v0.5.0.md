# UI-Vault v0.5.0

- 目录元数据、素材授权边界、参数控件及移动端无障碍治理。
- 中英双语短语检索、相关性与超大多组虚拟窗口。
- 预览超时恢复与原站入口；不把 iframe load 当作可交互证明。
- 独立 ZIP 内容哈希、React/Vue 原生按钮源码快照 Registry。
- 浏览器存储异常降级，保留原数据格式及三栏布局。

正式发布需通过 Linux、Windows、Chromium、axe、Firefox/WebKit、真实 Pages 部署和线上文件哈希校验。Vue 适配器是源码快照而非完整已验证安装包；第三方授权以来源说明为准。
