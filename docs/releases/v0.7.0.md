# UI-Vault v0.7.0

本版本聚焦专业工作台的视觉层级、短窗口适配、首屏加载、源码阅读及 Foundation Registry 复用体验。保留已有 528 项资产、资产 ID、收藏、用户偏好、原视觉基线及 iframe 安全边界。

## 主要改进

- 三栏与目录：宽屏标准模式适度拓宽目录，改善标题和次级信息层级，保留紧凑行距与用户窄栏偏好。
- 检索与首屏：全局搜索按需计算、缓存匹配信息，核心目录优先于可选健康快照，短窗口不再整体溢出。
- 参数检查器：按实际高度适配工具栏，统一错误颜色与键盘恢复行为。
- 源码与交付：短屏优先展示源码，折叠工具可展开；代码独立滚动，支持键盘聚焦。
- Registry：11 个模块的分类、依赖链、运行时、模块 JSON 和 CLI 命令。浏览器仅展示可信索引，不运行安装；CLI 仍负责完整性和冲突核验。
- 公共控件：设置浮层修复裁切，优化焦点恢复、状态语义及减少动效体验。

## 质量与发布边界

功能候选 19d9a1d 的 CI 45553510770 已通过，包含 358 项单元测试、33 项 Chromium 交互、9 项视觉基线及 75 张截图复审。参数拖动 P95 帧间隔 16.8ms，末次输入至确认 18.9ms；5000 项模拟目录实际挂载 20 行，P95 帧间隔 16.9ms。上述是候选环境采样，不代表所有设备的性能。

功能已合并至 main 3303995。正式版本仍需完整发布流水线（Linux/Windows、axe、Firefox/WebKit、Pages 及生产哈希校验），通过后由既有工作流创建精确提交的 Tag 与 Release。本候选不新增功能、依赖或权限，不修改 v0.6.0 Tag。
