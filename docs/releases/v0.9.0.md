# UI-Vault v0.9.0 发布候选

## 产品成果
- 精选资产：14 个本地重点资产的 28 个双视口场景巡检；Notion 受限 iframe 存储、准确持久化提示、独立源码同步及六档导航修复。7 个外部精选资源检查登记，其中 6 个独立站点实际加载，Tauri Desktop Kit 未登记站点。外部页面深层交互与封面尚未全面验收。
- Warm Workbench：独立材质快照、CSS、自定义材质库及版本化 Token CSS/JSON。仅背景色、渐变、阴影，保留布局与动效；可编辑恢复使用原材质 JSON，Token JSON 为 UI-Vault 自有解析值格式，非 DTCG 兼容声明。
- 组件复用：七个真实公开源码/依赖的精确资产白名单，加局部双主题适配共八份文件；独立临时 React 工程真实编译、键盘交互和减少动效。共享 CSS 仍可能同名冲突，不是完全隔离 npm 包。原始源码与通用 Foundation Registry 入口可往返，不改变安装 CLI。
- 稳定性：快照及材质导入共享最新读取序号和编辑版本。旧读取不会覆盖较新的选择、编辑或主动读取，导入后保留显式应用；不扩大文件访问或 iframe 权限。
