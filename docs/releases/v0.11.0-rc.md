Firefox 旧版日志出现 sandbox_extension_issue_file_to_process Operation not permitted 及 RenderCompositorSWGL 错误。使用外置与独立内置缓存均失败，新版使用自动及显式 profile、私有临时目录和系统临时目录均失败。现有证据表明阻塞在浏览器启动环境，而非已证实的产品页面缺陷；不关闭浏览器沙箱、不改系统权限、不把其他引擎通过外推为 Firefox 通过。实际系统根因未确定。启动设 15s 截止，新增本地验收入口以独立日志和子进程截止时间收口。

Edge 旧驱动曾在菜单选择及双弹窗确认发生偶发未触发；新版驱动也复现确认问题。原生尺寸移除无效变换后，原固定及新版驱动各完整通过一次。仍非长时稳定性认证。

## 本地门禁复现

保持私有数据目录独立于仓库；使用已准备的 Python Playwright/Pillow 环境：
- npm run check
- UI_VAULT_DATA 指向私有根目录，node scripts/product-registry.mjs verify
- UI_VAULT_AUDIT_OUTPUT 指向私有根下独立验收子目录，python scripts/audit-private-visual.py

四引擎任何失败均非零退出；报告只留私有目录。Firefox 未通过前不得宣称 V0.11 正式发布就绪。正式 CI 和生产部署校验仍为后续明确授权事项。
