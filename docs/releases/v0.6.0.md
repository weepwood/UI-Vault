# UI-Vault v0.6.0

本次版本聚焦工作台体验、资产检索、参数编辑与跨框架复用交付，保留已有资产 ID、收藏与设置存储、iframe 沙箱边界及第三方授权说明。

## 主要功能

- 目录：528 项资产基础标签完整，288 项原始指南审计；显式视觉风格标签覆盖 458 项，未对其余 70 项进行无证据分类。多词双语检索、目录会话恢复及多分面组合。
- 工作台：全局搜索分批加载、键盘定位、公共下拉菜单视口适配、源码高亮与复制/下载。
- 参数编辑：可调整高度的实时检查器、分组定位、四色标渐变、双层阴影、曲线、预设、统一数字校验与撤销；预览握手与通信异常恢复。
- 复用：11 个 Foundation Registry 模块，React/Vue 独立运行验收、Vue 锁定源码工程 ZIP、安装预检及只读 --verify。Registry 不携带运行时依赖，不自动覆盖文件，不代表第三方商业许可。
- 工程：组件 CSS 和字体样式统一版本指纹，保持已有视觉基线。

## 发布条件

功能基线 #123 已通过 Linux/Windows、354 项单测、27 项 Chromium 交互、9 项视觉基线、React/Vue 独立运行及 22/22 Registry 文件校验。正式版本仍须独立通过完整发布流水线，包括 axe、Firefox/WebKit、Pages 部署与线上关键文件哈希核验。只有通过后才允许自动创建精确提交的 Tag 和 Release。
