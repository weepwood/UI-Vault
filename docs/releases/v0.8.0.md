# UI-Vault v0.8.0

本版本集中交付现有三栏工作台内的真实组件实验、设计参数复用、视觉还原与双主题细节改进。保留用户确认的主站三栏、展厅内部导航、布局策略与预览安全权限。正式 CI 45635843633 成功（含 Windows、Chromium、跨浏览器、Pages 和生产校验），Tag v0.8.0 精确指向 db865df63a8de2c4d40840b896a8aa79af3ce28b，Release 已发布：https://github.com/weepwood/UI-Vault/releases/tag/v0.8.0 。

## 产品更新

- **组件展厅（#135、#140）**：真实 Button、SearchField、WorkbenchSelect、原生 Slider 与 Dialog 的属性调节；错误、禁用、加载演示、焦点与键盘交互。配置 JSON 同步真实控件，加载演示不联网。
- **设计实验室（#135、#137、#139）**：网格、玻璃材质、空间色场、工程界面、阅读排版、空间动效六配方，均支持三参数、三个预设、CSS/JSON、默认恢复；版本化 JSON 支持跨配方与新会话重放、旧格式和本地文件（8 KiB），严格验证字段、范围与步长。读取不自动应用，不执行输入内容，不上传文件。
- **视觉还原（#136、#137）**：WebGPU 不可用时显示明确标记的 CSS 简化球体，保留原始 WGSL；恢复历史 HarmonyOS Sans SC Medium/Bold 字体原字节及已恢复的原始插画，保留系统字体和渐变兜底。
- **主站体验（#138）**：统一局部控件表面、深浅主题滚动条与选中状态、命令面板悬停和键盘选择区别、减少动效和禁用反馈；不重构三栏或展厅导航。

## 已知边界

- CSS 降级不是原始 WebGPU 着色器；支持 WebGPU 设备上的原效果画质尚未实机验证。
- 历史字体和插画的来源保留，许可仍待核实，仅学习展示，不提供可再分发组件包。
- 状态演示并不等同完整表单业务校验或真实异步请求；独立组件交付仍依其实际 Registry 和复用说明。
- 外部站点实时可用性不能仅由 HTTP 或本地固定夹具证明；AI Skills 真实 Agent 安装执行仍待专项验证。
