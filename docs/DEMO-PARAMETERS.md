# Demo 参数协议 v1

首个试点仅为 `ui-foundation-kit` 的原始本地路径。资产 ID 和 preview 必须完全匹配；外站与未登记 Demo 不支持。主站不获得 same-origin 权限，不读取子文档，也不接受任意 CSS、URL 或代码。

消息字段：channel = ui-vault:demo-parameters，version = 1，assetId，action，requestId；apply 带 values。动作 read/apply/reset；子页回应 state（完整参数）或 error。父页核对当前 iframe、contentWindow、opaque origin "null"、requestId；子页核对直接父窗口与同站点 origin。由于目标子页为 opaque origin，父页发送必须使用 "*"，但只发送非敏感的白名单参数。3 秒超时允许重试。不使用消息进行导航、存储或代码执行。

`assets/core/demo-parameters.js` 是字段、校验与导出逻辑来源；单文件 Foundation Demo 内嵌同一核心，测试检测漂移。颜色只允许六位 HEX，数值必须是指定整数范围。协议通用校验预留 boolean/enum；本次实际字段为 color/number。导出 12 项变量快照，不是完整主题，不自动生成 hover 或 WCAG 保证。重置移除覆盖值。当前编辑不持久化，不改变公开资产源数据。新增资产必须显式登记并逐个验收。

## 第二批效果试点

Backdrop Studio (`aurora-field`) 9 项：42 种效果、10 套配色、强度、速度、柔化、动态/静态、颗粒、暗角、跟随。Liquid Orb (`liquid-orb`) 3 项：流速、播放、玻璃外壳。后者沿用现有渲染控制函数并尊重 reduced-motion；未纳入旧别名及外部站点。参数 JSON 是快照，不是完整渲染源码。构建及发布验收检查三项单文件 Demo 的 HTML 静态引用，不能证明动态 JS 依赖闭包。

## 暖色布局高级参数试点（候选）

原七项布局变量保持兼容，新增 13 项受控参数：渐变开关、终点颜色及角度，阴影颜色、不透明度、模糊和纵向偏移，四个百分比贝塞尔控制点、时长与抬升距离。仅通过固定键和值域生成 CSS；默认关闭渐变、阴影、悬停动效，不改变原版视觉。旧七项 JSON 快照与本地预设仅在存储导入时补齐默认值；消息仍严格要求完整参数，拒绝不完整的新格式与任意 CSS。独立 HTML 中同步核心；需通过真实浏览器、旧预设及 CSS 导出回归。此试点并非通用多色标渐变/多重阴影编辑器。

## 材质编辑第二阶段（候选）

暖色工作台增加两个可独立启用的中间色标，位置 0–100%、按位置稳定排序，最多四个色标；第二层阴影单独支持颜色、透明度、模糊、横纵偏移及扩展。总计 32 个受控字段。兼容旧 7/20 项完整快照和预设，部分新增字段拒绝导入。曲线图两控制点支持指针捕获、拖动及单次撤销历史；键盘用户仍可使用四个数值字段。消息仍仅接受完整白名单数值、颜色、布尔值；默认无新增视觉效果。新增真实浏览器四色情况、双阴影和拖动验证，待 CI。

## 材质操作第三阶段（候选）

沿用 32 个固定字段，色标条展示两个固定端点和已启用中色标；中色标通过指针捕获拖动，方向键 1%（Shift 10%），使用原历史记录及实时消息节流。阴影层启停通过原透明度字段（关闭为 0、重新启用为 15%），保留其他层参数；五种曲线预设一次性更新四个控制点。无任意 CSS 输入，无新增协议字段。待浏览器验收。

## 材质分组编辑（候选）

根据 #111 实际截图，布局基础字段移到首屏；渐变色标、阴影样本和曲线图分别放在对应字段组，五个分组按钮定位并聚焦标题，不隐藏字段。中色标可快捷增删，保留颜色/位置，Home/End 可到达端点；阴影重新启用恢复本次编辑关闭前的非零透明度（未记录时 15%）。不新增协议字段。待 CI。

### 阴影层顺序与固定分组入口

暖色工作台追加 `shadowReversed` 布尔字段（默认 false），从 32 项扩为 33 项。交换顺序仅反转 CSS box-shadow 绘制顺序，不转换或丢弃任何层的独立值；旧完整 7/20/32 项文件和预设补齐默认值，实时协议仍要求完整白名单字段。参数停靠区分组导航在内部滚动时固定，保留焦点跳转。新增真实顺序、撤销与双视口几何检查，候选须通过完整 CI。
