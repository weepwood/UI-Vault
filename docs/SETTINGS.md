# UI-Vault 设置中心

设置是**工作台内的专属视图**，不是独立网页，也不是模态弹窗。设置区域内部再分为 **分类导航 / 配置详情** 两栏：左侧切换「外观、界面、字体、浏览体验、关于」，右侧仅显示当前分类的设置项。

- 点击第一栏左下角「设置」，主导航继续保留；原本“项目列表 + 预览画布”的右侧两栏合并为设置工作区。该工作区再划分为约 190–238px 的设置分类栏与可滚动的设置详情栏。
- 从第一栏点击资源分类、收藏筛选或搜索，立即恢复原先三栏布局；既有预览 iframe 不重新创建。
- 访问 `/?view=settings` 可直接打开设置视图，浏览器前进/后退支持视图切换；保留原 `?asset=id` 深链接与项目预览状态。
- 旧的 `settings.html` 地址仍可打开，会重定向到 `./?view=settings`，避免历史书签失效。
- 在手机上，设置分类栏转换为水平可滚动的分类标签；顶部保留资源目录按钮，打开后只显示第一栏导航。
- GitHub 仓库入口位于设置内的「关于」分区，不放在左侧导航底部。
- 设置即时保存于当前浏览器的 localStorage（键 `ui-vault:preferences:v1`）；收藏与偏好独立存储，重置设置不清空收藏。
- 下拉菜单与目录筛选复用 `enhanceSelect()`，支持键盘操作、显示选中状态和原生 select 回退。分类按钮提供 `aria-current`，当前分类内容的显示状态同步更新。
- 外观页提供实时颜色预览，字体页提供中英文排版样张；这些预览由原有 CSS Token 直接驱动，不引入额外数据或装饰依赖。

## 设置项

| 分组 | 可设置内容 | 默认 |
| --- | --- | --- |
| 外观 | 浅色 / 深色 / 跟随系统；强调色蓝 / 青绿 / 紫 | 跟随系统、蓝 |
| 界面 | 舒适 / 紧凑列表、标准 / 窄侧栏 | 舒适、标准 |
| 字体 | 霞鹜 975 圆体 / 系统无衬线 / 系统衬线；12–15px | 975 圆体、13px |
| 浏览体验 | 自适应 / 手机 / 平板 / 桌面预览；跟随系统 / 减少动画 | 自适应、跟随系统 |
| 关于 | GitHub 项目源码链接 | 不可编辑 |

## 技术结构

- `index.html`：在工作台内嵌入设置视图和 GitHub 相关入口。
- `assets/app.js`：设置与项目浏览间的视图切换、浏览器历史记录和移动端目录状态。
- `assets/core/settings.js`：共享默认值、存取、校验、应用主题及选择器初始化；首页不再依赖设置弹窗 DOM。
- `assets/styles.css`：页面布局与原有设计 Token；适配窄屏。
- `scripts/build.mjs`：发布单一工作台入口的带指纹脚本；`settings.html` 作为兼容重定向页面保留。
- `scripts/check-dist.mjs`、`tests/settings*.test.mjs`：验证工作台内视图、图标、数据字段、静态发布和样式。

## 字体与项目预览边界

网页使用本地 WOFF2 字体子集；构建器会扫描包括 `settings.html` 在内的界面字符。设置的字体/外观只应用于主站外壳和设置页面，不跨 iframe 强制覆盖其他 Vue、React 或页面镜像项目。

## 后续扩展

可增加 JSON 配置导入/导出、按项目保存设备预览模式、更多键盘快捷键、可拖拽导航宽度。添加设置项时需同步更新 `DEFAULT_SETTINGS`、`OPTIONS`、`settings.html` 和回归测试，避免出现仅展示 UI 而不实际保存的假设置。
