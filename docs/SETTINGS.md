# UI-Vault 设置中心

通过顶部工具栏的「设置」按钮进入，无需登录或后端。修改立即生效，保存在本设备当前浏览器的 localStorage（键名 `ui-vault:preferences:v1`）。

## 功能与默认值

| 分组 | 设置项 | 选项 | 默认 |
| --- | --- | --- | --- |
| 外观 | 主题 | 跟随系统 / 浅色 / 深色 | 跟随系统 |
| 外观 | 强调色 | 蓝 / 青绿 / 紫罗兰 | 蓝 |
| 界面 | 列表密度 | 舒适 / 紧凑 | 舒适 |
| 界面 | 侧栏宽度 | 标准 / 窄侧栏 | 标准 |
| 字体 | 字体家族 | 霞鹜 975 圆体 / 系统无衬线 / 系统衬线 | 霞鹜 975 圆体 |
| 字体 | 字号 | 12 / 13 / 14 / 15 px（关键界面文字同步偏移） | 13 px |
| 浏览 | 默认预览尺寸 | 自适应 / 手机 / 平板 / 桌面 | 自适应 |
| 浏览 | 动效 | 跟随系统 / 减少动态 | 跟随系统 |

「恢复默认设置」仅重置上述外观与预览偏好，**不会删除收藏、搜索内容和仓库资产**。

## 代码结构

- `assets/core/settings.js`：选项白名单、存取、渲染同步、主题跟随系统、重置。
- `assets/styles.css`：颜色 Token、界面密度、字体、侧栏宽度、设置对话框。
- `index.html`：设置入口与语义化对话框（原生控件，可键盘操作）。
- `assets/app.js`：生命周期接线、保存的默认预览尺寸与现有 iframe 布局复用。
- `tests/settings.test.mjs`：入口、默认值、容错和主题回归测试。

## 约束和演进

1. 仅修改 UI-Vault 的外壳，不修改 iframe 内独立的 Vue/React/镜像项目，以防跨域限制与视觉污染。
2. 使用原生 `dialog` 保持焦点和 Escape 关闭行为；浏览器不支持存储时仍可在当前页面调整设置。
3. CSS 通过 `data-theme`、`data-accent` 等属性与语义变量控制，避免在 JS 中逐个修改组件样式。
4. 移动端侧栏始终遵守既有响应式结构，「窄侧栏」只适用于桌面宽度。
5. 霞鹜 975 圆体当前从上游静态文件加载，首次字体文件较大；建议后续按许可证处理为合理的网页字形子集缓存。
6. 后续扩展可增加导入/导出偏好、快捷键绑定、预览网格背景、按项目记忆预览尺寸。不要在第一版引入不必要的全局状态库。
