# 视觉风格页面去模板化设计

## 目标

参考开源 anti-slop 设计技能中的审阅方法，优化 UI-Vault「视觉风格」分类的 56 个本地页面。改进对象是页面的展示框架、信息层级和样例说明；各个 Demo 的专属风格仍是内容主体。

## 调研依据

- `Studio-Groei/anti-slop`：先整理具体审美参考，再按页面意图迭代，避免一次性套用统一模板。<https://github.com/Studio-Groei/anti-slop>
- `heydamir/unslop`：从具体页面诊断版式、文案与视觉问题，再依据产品语境逐项修订。<https://github.com/heydamir/unslop>
- UI-Vault `AGENTS.md` 与 `DESIGN.md`：保留独立 Demo 的艺术风格，主站避免模板装饰，检查真实内容、来源、窄屏和键盘使用。

## 页面范围

共 56 个本地页面，按现有结构分三组：30 个 Atlas 风格说明页、12 个 Frame Lab 样例、14 个客户端 UI 样例。

### Atlas 风格说明页（30）

- 让实际风格样本成为页面视觉焦点。
- 以更有层级的案例阅读顺序组织说明、适用与风险、调色板和 Token。
- 减弱重复白色卡片的边界感，沿用每个样本内部的字体、配色和布局。

### Frame Lab 样例（12）

- 保留可操作的样机和可比较的样例内容。
- 减少样机外壳、说明卡、Token 卡之间重复的边框和圆角。
- 明确指标与列表是示例数据；保留主题特定的几何、颜色、密度和交互。

### 客户端样例（14）

- 保留各客户端样机自己的品牌层级、颜色和布局结构。
- 让外层说明与来源资料帮助读者区分产品模拟、设计观察和官方参考。
- 保留现有可操作控件，并加强窄屏可读性与焦点状态。

## 实现方式

- 新建 `assets/style-atlas/reference-shell.css`，按 body 的 `data-reference-shell` 值为三组提供独立样式规则。
- 为 56 个本地 HTML 页面添加分组标记并加载该样式表；现有 HTML、文案、数据、来源和主题预览继续沿用。
- 不安装或复制第三方技能仓库代码，不新增运行时依赖。
- 保留键盘焦点、现有交互、响应式行为与 `prefers-reduced-motion` 支持。

## 验收

- 56 个本地页面均加载正确的分组样式，现有各页专属样机仍可见且外观有区分。
- 桌面、平板、手机宽度下无横向溢出，长标题和说明内容可阅读。
- Frame Lab 与客户端模拟仍能交互；颜色与 Token 复制按钮可继续使用。
- 键盘焦点清晰可见，减少动态效果偏好保留。
- 运行静态构建与差异检查，并用本地浏览器检查三组代表页面的实际渲染。
