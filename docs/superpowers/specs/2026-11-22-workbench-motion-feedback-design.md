# 工作台状态反馈与按压动效设计

## 目标

让 UI-Vault 工作台中的项目选中状态和收藏操作更容易感知，同时延续已有的克制视觉风格。动效只响应用户操作，不加入列表自动进场效果。

## 方案

### 项目选择

- 为项目行的选中底色、图标边框和强调色增加约 160 ms 的平滑过渡。
- 继续使用现有 `.is-selected` 状态，不新增 JavaScript 状态或数据字段。
- 不移动列表行，也不改变列表的排序、筛选或滚动行为。

### 收藏反馈

- 收藏按钮的按下状态增加轻微缩放反馈。
- 收藏状态的图标填充、文字颜色和底色使用短过渡同步变化。
- 保留现有 `aria-pressed`、键盘焦点和 disabled 状态。

## 动效与无障碍

- 优先使用 `transform`、颜色与边框等局部属性，时长保持在 140–180 ms。
- 尊重系统 `prefers-reduced-motion` 和 UI-Vault 的减少动态效果偏好；减少动态效果时取消按压缩放与过渡。
- 保持可见的 `:focus-visible` 样式，选择状态仍由颜色/背景表达。

## 实现边界

- CSS-only，修改项目行和基础控件样式。
- 不新增依赖，不改收藏逻辑，不改预览 iframe 或 Rare UI 子项目。

## 验收

- 选择不同项目时，原选中态平滑退出，新选中态平滑进入。
- 收藏与取消收藏均有短促、可辨认的状态过渡；鼠标按下有轻微触感反馈。
- 减少动态效果下，以上动画收敛为即时状态变化。
- 工作台正常构建，窄屏和桌面布局不发生位移或布局抖动。
