# UI-Vault 长期建设路线

本文区分已实现的基础与建议新增的功能，不以旧版文档阶段名称作为已发布版本号。

## 现有基础

- [x] React 19 三栏工作台、目录/预览/设置的统一状态管理。
- [x] 独立 JSON 资产目录与生成索引，按类别及标签搜索。
- [x] 本地 HTML Demo 与跨仓 React/Vue 网站 iframe 预览。
- [x] 源码查看、单文件下载、多文件 `sourceFiles` 协议。
- [x] 共享 Design Tokens、Lucide、UI Foundation Kit。
- [x] Node 校验、白名单构建、Chromium 视觉回归和 GitHub Pages 部署。

## P0：工程治理与授权风险

- [x] 非自包含 Demo 的单文件复制标记修正。
- [x] iframe 额外能力由资产元数据白名单控制。
- [x] 第三方资产与授权风险文档。
- [x] CI 使用 `npm ci` 并发控制。
- [x] 添加 `.gitattributes` 统一换行符为 LF，校验/测试对 CRLF 容错，并新增 Windows CI 校验任务，保证本地开发可复现。
- [x] 确定根目录原创代码的 LICENSE（MIT，仅覆盖原创内容，第三方素材见 THIRD_PARTY_NOTICES.md）。
- [ ] 核实或替换未确认可以再分发的第三方图片和字体。
- [ ] 在 GitHub Settings 启用 main 分支 Ruleset 与 required checks。

## P1：架构规范与质量

- [x] Schema 与运行时元数据检查同步，拒绝未知字段。
- [x] 当前架构、扩展指南、贡献与安全文档。
- [x] Dependabot 和定期外部 `siteUrl` 检查。
- [ ] 引入 ESLint + React Hooks 检查和格式化工具（先评估现有代码的迁移成本）。
- [ ] 将部分基于源码正则的测试升级为 React 行为测试。
- [ ] 增加可访问性检查（如 axe-core）、浏览器兼容冒烟测试。
- [ ] 资产来源与图片/字体许可证的自动化核验流程。

## P2：设计资产工作流

- [x] 组件复用程度标记：从既有元数据派生为目录筛选（已验证 / 可安装 / 可复制 / 本地实现 / 外部项目），新增资产自动归级；「已验证」待手工精选评审到 stable 后生效。
- [ ] 面向本地精选资源的授权封面与尺寸压缩流水线。
- [ ] 设计 Token 浏览、编辑、版本比较和 CSS / JSON 导出。
- [ ] 两个 Demo 的并列对比、视口同步和效果参数差异。
- [ ] 本地收藏与偏好导出/导入，支持备份恢复。
- [ ] 通用 Demo 参数描述协议，并使用安全的消息桥控制沙箱内 Demo。
- [x] 首批本地多文件静态 Demo 的显式 ZIP 打包、发布白名单和内容验证。
- [x] 外部 GitHub 项目的整仓 ZIP 快照入口（并明确其不一定是当前子项目）。
- [ ] 扩大已验证可独立下载的 Demo 范围，并自动验收 ZIP 内相对资源引用。
- [ ] 多框架完整源码与工具链导出协议（含构建说明、锁文件和依赖版本）。

## 统一项目运维视图

- [x] 项目级代码检查、GitHub Deployments/Pages 证据、资产级 iframe 限制与 HTTP 状态分开采集。
- [x] `?view=operations` 可筛选视图：代码/部署/预览、搜索、项目与资产展开。
- [x] 离线未知快照、定期刷新和浏览器回归，不接管跨仓源码与流水线。
- [ ] Netlify/Vercel 平台精确部署状态须连接提供方或消费可信部署记录，不应由 HTTP/Actions 代替。
- [ ] iframe 内容真正可交互的证明需要合作站点可信 ready 协议或自动化浏览器验收；当前不把 load 当作成功。

## Project / Asset 分层管理

- [x] 33 个 Project 注册表与 Schema、126 条 Asset 的 `projectId` 关联和双清单校验。
- [x] 可选按项目分组，项目详情显示来源仓库和关联资产数量。
- [x] 来源仓库与站点 URL 分别巡检。
- [x] 公开 GitHub API 只读快照核验默认分支、最近推送、仓库归档与默认分支 Actions，离线降级；不把 CI 等同于发布。
- [ ] 精确的各仓库实际部署状态（Pages、Netlify、Vercel）仍需与对应部署提供方核验，不能仅凭 Actions 结果推定。

## P3：可维护的设计系统

- [ ] 正式验证的 React/Vue 组件安装包、registry 或 CLI。
- [ ] 大型目录的虚拟列表、搜索索引、封面缓存与性能预算。
- [ ] 独立 Demo 的构建适配器和多框架 CI 约定。
- [ ] 发布版本 Changelog、变更影响说明与迁移策略。

## 暂不优先

账号系统、数据库、多端服务端同步、全仓统一框架迁移、未经授权的静态站点镜像、未经验证的 AI 自动生成可安装组件。
