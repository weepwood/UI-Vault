# UI Vault 长期演进路线

## v0.2 · 已落地的基础

- 每条资产独立 JSON + 自动生成前端聚合索引
- 分类导航数据化，避免增加分类时改展厅源码
- 搜索、收藏和视图渲染的模块化
- 本仓 Demo / 外部参考创建脚手架
- 静态资源白名单构建、Node 原生测试、自动部署
- 保持原有 Demo URL 与收藏 ID 兼容

## v0.3 · 资产收集效率

- 按需截取可授权 Demo 的真实封面（需网络及渲染环境）
- 封面压缩与尺寸约束，避免海量资源拖慢首屏
- 资产详情支持多种视口宽度和深浅主题预览
- 生成 HTML/CSS/JS 代码拆分视图
- 批量导入经过审核的 GitHub Star / 外部网址

## v0.4 · 设计复用体系

- 视觉设计 Token 浏览、编辑、CSS/JSON 导出
- 设计规范（DESIGN.md）与 Agent Prompt 导出
- 组件可复用状态标记：参考、可复制、可安装、已验证
- Vue/React 单独构建适配器、打包产物路径自动发现
- 组件对比、版本记录及响应式截图回归

## v1.0 · 可维护的个人设计系统

- 只对正式验证的组件提供 npm / shadcn Registry 或 CLI 安装能力
- 细粒度主题、组件依赖与许可证追溯
- 较大规模资源的虚拟列表/搜索索引与封面缓存
- 可选多端同步，避免将用户私有内容放入公开 Pages

**不优先做**：复杂账号系统、服务端数据库、未经许可的站点镜像，以及自动把不同框架源码无条件转换成可安装组件。
