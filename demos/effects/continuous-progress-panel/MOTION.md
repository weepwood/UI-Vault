# 进度面板 · 连续布局动效规范

参考：用户提供的 Designed to Scale 截图。截图尺寸 570×682；本实现按约 2× 截图比例推定 CSS 尺寸，并非原站实际计算样式或动画实测。原站实时源码与录屏未获得。

## 视觉规范
- 面板宽 264px，圆角 12px，描边 1px，内边距 15–16px；低对比暖纸底色、内侧高光、轻微投影。
- 标题、计数、进度条始终保留；分类列表为唯一变高的裁剪层，列表自然尺寸不被缩放。
- 默认底边固定，上沿随高度改变；可切换为顶边固定对照。原站实际锚定方式需实测。
- 勾选 9 个分类可演示总进度；不是原站课程完成数据。

## 动效契约
- 使用自然内容高度 H（ResizeObserver），目标高度为 H 或 0；不使用固定 max-height 猜测。
- 首选临界阻尼弹簧：质量 1，ω=21/s，刚度 k=441/s²，阻尼 c=42/s。约 300–420ms 达到视觉稳定，取决于行程与停止阈值。
- 精确离散解：d=h-target, b=v+ωd, e=exp(-ωdt); h'=target+(d+b·dt)e, v'=(v-ωb·dt)e。反向只修改目标，保留当前 h,v；零高度物理边界截断。
- 同一归一化高度 p=h/H 驱动内容 opacity=min(1,1.9p)、位移 -5(1-p)px、箭头旋转 180(1-p)°。不对整个面板 scaleY，避免文字、圆角、边框被压扁。
- CSS 对照使用 WAAPI cubic-bezier(.22,1,.36,1)，360ms；反向以当前高度重启，不保证速度连续。
- 支持 reduced-motion、键盘原生按钮、aria-expanded、折叠内容 inert、焦点恢复。
- 演示中的速度/曲线读数使用 RAF，正式业务应移除监测并在稳定后停止调度；高度动画会触发布局，不声称完全由 GPU 合成。
