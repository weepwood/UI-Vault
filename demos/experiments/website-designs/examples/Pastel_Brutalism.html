Components

Bordered Cards & Flat Surfaces

thick outlines, hard shadows, pastel fills -- honest and tactile

■

Thick Black Borders

Every element is outlined with solid 3px black strokes that define shapes with absolute clarity. No subtle hairlines here.

Structure Core
▲

Hard-Offset Shadows

Zero-blur, fixed-pixel-offset shadows create a flat cutout-paper effect. Elements float above the canvas as physical objects.

Shadow Depth
●

Flat Color Fills

No gradients, no transparencies. Each surface is a single solid pastel tone, maintaining the brutalist honesty of the design system.

Color Flat
✎

Oversized Typography

Headlines use extra-bold fonts at architecturally scaled sizes. The typographic weight matches the structural boldness of the borders.

Type Bold
★

Tactile Interactions

Hover states shift shadow offsets and translate elements, creating a satisfying "press-in" sensation that reinforces the physical metaphor.

Hover UX
☰

Visible Grid Structure

The layout grid is never hidden. Columns, rows, and gutters are perceptible through consistent alignment and deliberate uniform spacing.

Layout Grid
Visual Effects

CSS Patterns & Textures

all structural, zero blur -- pure CSS, no image assets

Checkerboard

Intersecting 45-degree linear gradients on a pastel base create a classic architectural grid pattern.

Pastel Stripes

Repeating diagonal stripes cycle through the core palette, creating a candy-toned visual rhythm.

Dot Grid

Small radial-gradient dots on a pastel surface evoke grid paper and technical drawing aesthetics.

Stacked Layers

Nested bordered rectangles with hard shadows create visual depth through offset layering.

Cross Hatch

Horizontal and vertical line grids on buttercream mimic the raw construction grid of architectural plans.

Color Block Mosaic

A flat grid of solid pastel tiles separated by dark lines -- the patchwork quilt effect in pure CSS.
