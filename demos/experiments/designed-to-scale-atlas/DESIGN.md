## 01. 设计定位与证据边界

参考：[Designed to Scale 原站](https://designed-to-scale.vercel.app/#/)、[课程介绍](https://designedtoscale.app/learn/)、[2026-11-18 第三方技术拆解](https://lijianfei.com/post/designed-to-scale-isometric-svg-engine/)。

原站入口可访问文本，但本次环境无法执行其 SPA 或下载生产 CSS，未取得原站实时截图、DOM computed style 或字体文件。以下用 **R** 标识第三方拆解报告的参数（非本次独立测量），用 **D** 标识本设计系统的原创归纳/实施值。原站课程结构、分步动画、搜索和进度由课程介绍支持。本规范不是原站像素级复刻，也不宣称其源代码或素材为开源。本演示从零实现，无原站资产、课程文本或代码。

核心：把工程知识变成一本可操作的技术图册。纸张作为环境，墨线作为结构，粉彩作为数据编码，运动作为解释。页面框架保持安静，主要注意力归于图解和当前步骤。

## 03. 信息架构

桌面采用左侧目录 + 主工作区。目录包括章节编号、课程标题、学习状态；顶部提供位置、主题与辅助入口。主工作区依次为课程标题、图解舞台、播放控制、当前步骤解说。主工作区最大宽度 1280px，避免阅读行无限扩展。图解舞台占主导，不把每一段解释包在孤立卡片里。

移动端：≤760px，目录折叠为可展开菜单，内容单列；舞台保持足够高度，SVG 默认适配宽度，另提供平滑放大、指针拖动漫游与 Fit 复位，操作按钮换行；演示控件高 36px（窄屏辅助按钮约 29px，生产环境应扩大触控热区至 44px），避免横向溢出。≤480px 取消装饰性元数据，图例紧凑显示。

## 05. 2.5D 图解规范

- 使用原生 SVG，固定逻辑坐标 960×440，视口等比缩放。2:1 轴测投影 `u=(x-y)*s, v=(x+y)*s/2-z`（符号与参考报告不同，等价风格）。水平:垂直斜轴比 2:1；设备顶面亮、侧面暗、统一墨线。图元保留稳定锚点。
- 服务器：三面盒体+机架槽；客户端：平面屏幕+底座；数据库：椭圆顶盖+筒身；缓存/队列：盒体+容量槽。浅色填充编码类型；同色系明度区分面。标签独立于实体，使用简明术语，不遮盖活动连线。
- 地面网格低对比度，与物体投影统一；非活动路径灰色虚线，活动路径实线或短虚线+明确箭头。请求橙色，响应绿色。连接边缘优先避开节点，不让线穿过实体。
- 固定图元以强调因果变化；拓扑切换才更换场景。大规模场景可引入包围盒裁剪、深度排序、稳定相机与 HUD 避障。当前演示采用手工布局，并未实现通用自动布线引擎。

## 06. 连续动效与教学叙事（V2）

每一步对应一个语义动作，而非全画布刷新。第三方拆解报告描述了原站的路径弧长发包、对象渐进演化、镜头稳定与暂停/回放；下面是演示独立实现的行为合同和数值。

| 动作 | 规则 |
| --- | --- |
| 节点显现 | 保留同一课程 SVG 节点；新参与节点从低透明度渐显，初次场景轻微抬升；360ms cubic ease-out。中断从当前 alpha/lift 继续。 |
| 数据包 | 轴测小盒，墨线包边；沿 SVG 路径弧长飞行，1750ms 到达；回程按反向弧长计算。 |
| 到达 | 包淡出 220ms，终点描边涟漪与勾号 850ms；仅表示示意中的到达，不是实测成功率。 |
| 循环 | 单周期 2800ms；当前刻度填充使用同一时间源。 |
| 暂停 / 继续 | Space 或播放键冻结时钟、包、节点和步骤内进度；继续沿当前时刻，不重置。 |
| 重放 | R 或回放键重置当前周期；不改变课程与步骤。 |
| Auto | 独立开关，周期结束推进一步，最后一步完成后停止。手动切步关闭 Auto。 |
| 镜头 | 双击或 + 放大，拖动平移，Fit 复位。指数阻尼时间常数 85ms；目标更新不重置当前视口。相邻步骤保留镜头。 |
| 文本 | 280ms 轻微入场令牌；禁止全屏闪烁。 |
| 后台 | visibilitychange 暂停帧循环，恢复时重置时间基准；dt 上限 50ms。 |
| 减少动态效果 | 立即应用节点和镜头状态，不绘制移动包或涟漪；Auto 仍可作为用户主动启用的步骤导航。 |

未实现原站可能具备的通用相机 HUD 避障、动态深度排序、实体边界自动裁剪、多包并发及失败粒子。当前图元与连线仍为手工场景；不宣称等同原站引擎。

## 07. 示例代码约定与复用

本目录 `index.html` 是独立的 HTML/CSS/JS 实现，零构建依赖、零远程资源。主题变量与以上表格一致；三个课程共 15 个步骤，状态由数据驱动，非真实网络或性能仿真。可直接打开或静态托管。复用时优先抽离 Token → 基础控件 → 图元 → 场景数据 → 播放器；不要将某个业务场景写死到通用播放器中。
