使用说明

页面包含实验 Flag 和正式浏览器设置，两类入口会分别标明。正式设置请优先使用浏览器的正常设置页面；实验 Flag 可能随版本变化或被移除；“源码中存在”也不等于你的版本一定支持。资料最近核对于 2026-11-23，具体以当前浏览器的设置界面为准。

Chrome 使用 chrome://flags，Edge 使用 edge://flags。点击某项的“前往设置”或“定位 Flag”，尝试打开对应页面。若浏览器阻止网页访问内部地址，地址已经复制：按 Ctrl / ⌘ + L 聚焦地址栏，再按 Ctrl / ⌘ + V、回车。

  • 更改前记录原值；每次修改一项并重启验证。
  • 出现异常时，把改动的 Flag 设回 Default，必要时在 Flags 页面选择 Reset all。
  • 部分功能已经迁移到正式设置，旧 Flag ID 可能已失效。
  • “我的清单”只记录你的计划，不会读取或修改浏览器真实的实验开关。
  • 可选的本地浏览器扩展可实现真正一键打开内部页，无需更改浏览器安全策略。
